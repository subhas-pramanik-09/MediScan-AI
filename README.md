## Description :

A smart and scalable ML-powered health prediction system that can help detect the risk of three major diseases:
  1. Diabetes 
  2. Heart Disease 
  3. Parkinsons Disease 

Each model is trained on real-world datasets and optimized for accurate results:

▪ Diabetes & Parkinsons models are built using Support Vector Machine (SVM) for robust classification.
▪ Heart Disease model uses Logistic Regression for its simplicity and interpretability in medical data.

⚙ Technologies Used:

  - Python 
  - Scikit-learn 
  - Pandas & NumPy 
  - Streamlit (for deploying an interactive and user-friendly web app)

🎯 Model Accuracies on Test Data:

   - Diabetes: 77.27%
   -  Heart Disease: 81.96%
   -  Parkinsons Disease: 87.17%
